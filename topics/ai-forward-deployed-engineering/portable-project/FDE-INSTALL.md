# AI Forward Deployed Engineering — Portable install tree

To install, copy `.fde/` into the project and append the whole of [AGENTS.fde.md](AGENTS.fde.md) to the existing `AGENTS.md`, or create it; use the optional Cline rule instead only if you do not use the section. Every path here is prefixed for this pack, so copying it does not overwrite another Senoni pack; still, copy only what is listed. Run `python3 .fde/check_install.py` from the project root.

Read [fde-memory.md](fde-memory.md) as a reference, not always-loaded context, and start with [.fde/README.md](.fde/README.md). Check actual loading in a fresh session. [Sources](.fde/90-sources.md). No customer data or source publications are included.
