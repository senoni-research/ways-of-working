# Cost Improvement Delivery & Value Realisation — portable handbook

Version 0.1.0 · 13 October 2026 · Companion review draft for Cost & Value Engineering 0.3.3

For OpenCode, Cline or another agent that reads `AGENTS.md`, install Cost & Value Engineering first. Then copy this tree's `.valuedelivery/` directory and append the section in `AGENTS.valuedelivery.md` to the project's existing `AGENTS.md`, after the base section. Do not replace that file or install a second companion entry route. Cline users may use the optional `.clinerules` entry instead of the section. Run `python3 .valuedelivery/check_install.py` from the project root and confirm in a fresh session that the files actually loaded.

Modules, recipes, source notes and templates below are generated from one canonical source. References to base files are written as `.costvalue/...` paths rather than links because they live in the separately installed base pack. No customer data, source publications or private training material are distributed. Synthetic examples and executable arithmetic are not industrial, financial or live-agent validation.
