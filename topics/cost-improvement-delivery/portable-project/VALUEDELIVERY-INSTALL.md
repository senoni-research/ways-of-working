# Cost Improvement Delivery & Value Realisation — portable install tree

Install Cost & Value Engineering 0.3.3 first. Then copy `.valuedelivery/` into the project and append the whole of [AGENTS.valuedelivery.md](AGENTS.valuedelivery.md) to the existing `AGENTS.md` after the base section; use the optional Cline rule instead only if you do not use the section. No file here has the same path as a base file, so copying cannot overwrite the base; still, copy only what is listed. Run `python3 .valuedelivery/check_install.py` from the project root.

Read [valuedelivery-memory.md](valuedelivery-memory.md) as a reference, not always-loaded context, and start with [.valuedelivery/00-activation-and-boundary.md](.valuedelivery/00-activation-and-boundary.md). Check actual loading in a fresh session. [Sources](.valuedelivery/90-sources.md). No customer data or source publications are included.
