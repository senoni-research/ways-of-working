# Build and validation

Python 3.10 or later, standard library only. No installation, network, source notebook execution, model loading, or provider request is needed.

From the complete package root:

```bash
python3 tools/build_pack.py .
python3 tools/build_pack.py . --check
python3 tools/validate_pack.py .
python3 tools/test_validate_pack.py .
python3 -m unittest discover -s reference -p 'test_core.py' -v
```

`canonical/` is the editable source. The portable and Cursor module trees, recipe reference, individual recipes, standalone books, source register, root docs and loaders are generated. Integration prefaces and generic loader are explicit canonical inputs. Metadata and source records remain separate from domain prose.

`render(root)` returns expected bytes without writing. The validator compares every generated artifact with this canonical rendering, then independently checks the manifest, exact pack inventory, Markdown/rule structure and links, loader references, and source-origin handling. It never calls the builder's mutating write path. Validation sets Python's no-bytecode flag to avoid even import caches in the source tree.

The manifest records canonical/support hashes and generated byte/word/hash values. These checks detect internal drift, not malicious coordinated replacement of both source and validator. Review changes to the generator, canonical guidance and tests as code. Hashes are not proof of methodological truth or source authorship.

The regression suite first requires a valid unchanged release, then mutates temporary copies and asserts the expected diagnostic category and target. Some cases propagate a canonical change with the pure renderer so a link or loader check can be exercised without a stale-file gate masking it. No-op mutators and validator crashes are errors, not passes. The supplied package-root argument is honored.

The numerical reference tests are separate from package-integrity tests and from B01–B40 behavioral specifications. They verify original arithmetic on synthetic inputs, not complete challenge reproduction or live coding-agent behavior.
